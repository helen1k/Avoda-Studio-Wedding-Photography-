# Avodart Studio — Wedding Photography

A mobile-friendly wedding photography website designed for GitHub + Netlify.

## Files
- `index.html` — website content, gallery and booking form
- `style.css` — design and responsive layout
- `script.js` — mobile menu
- `assets/` — put your photos here

## Before publishing
1. Replace the sample WhatsApp number, Instagram username and email in `index.html`.
2. Add your images to `assets/`.
3. The hero image should be named `hero.jpg`.
4. Gallery images should use names such as `photo-01.jpg`, `photo-02.jpg`, etc.
5. You can add more gallery cards in `index.html` whenever you want.

## Netlify
Connect the GitHub repository to Netlify. Netlify will automatically deploy new commits, so later photo uploads/website edits can go live without manually uploading to Netlify each time.

The booking form uses Netlify Forms (`data-netlify="true"`).
